## Start here

Install wtm, let `wtm go` change your directory, and set up a repository once.

```bash
brew install LucasPcq/tap/wtm
echo 'eval "$(wtm shell-init)"' >> ~/.zshrc   # ~/.bashrc for bash
cd your-repo && wtm init
```

[Getting started](__BASE__/guide/getting-started/) takes you from there to two branches running side by side, in ten minutes.

Go, binaries and a specific version: [Installation](__BASE__/guide/installation/).

Linux and WSL2: [Platform support](__BASE__/guide/platform-support/).

## The life of a branch

### Created, ready to code

`wtm create` makes the worktree from any base, copies its `.env` files and runs your hooks.

- [Configuration](__BASE__/guide/configuration/): `config.toml`, how `.env` files are provisioned, `on_create` and `on_clean` hooks.
- [A pnpm or turbo monorepo](__BASE__/guide/recipes/#a-pnpm-or-turbo-monorepo), [a docker compose app](__BASE__/guide/recipes/#a-docker-compose-app): complete setups to copy.

### Running, each with its own stack

`wtm run up` starts the worktree's jobs on its own ports, under its own Compose project, at its own address. One person describes the stack in `run.toml`, the team imports it.

- [How wtm run works](__BASE__/guide/how-run-works/): the job environment, ports, what `wtm run init` proposes.
- [Jobs, profiles and runners](__BASE__/guide/jobs-and-profiles/) and [isolation](__BASE__/guide/isolation/): what a worktree runs, and what it shares with its source.
- [Shared services](__BASE__/guide/shared-services/): one postgres for the repository, a database per worktree.
- [Named URLs](__BASE__/guide/addressing/) and the [`run.toml` reference](__BASE__/guide/run-toml/).

### Kept in order

Every worktree records the branch it came from; `wtm sync` rebases a chain, parents first.

- [Stacked pull requests](__BASE__/guide/recipes/#stacked-pull-requests): `tree`, `sync` and `reparent` on a real stack.

### Gone once merged

`wtm clean` and `wtm prune` remove worktrees with their jobs and data, and refuse to lose work.

- [Where wtm keeps its state](__BASE__/guide/state/) and [troubleshooting](__BASE__/guide/troubleshooting/): a port in use, a crashed job, a `.env` out of date.
