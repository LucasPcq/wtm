## A worktree ready to code, in one command

`git worktree` gives each branch a directory. Everything else is still on you: copy the `.env`, install dependencies, remember which directory holds which branch, and run two branches' dev servers without them fighting over the same ports, containers and databases.

<CardGrid>
  <Card title="Provisioned" icon="rocket">
    `wtm create` copies the `.env` files, runs your `on_create` hooks (`pnpm install`, …) and shifts the ports. `wtm go` jumps into it.
  </Card>
  <Card title="Cleaned when merged" icon="approve-check">
    `wtm prune` removes every worktree whose PR is merged, in one pass, and refuses one that still holds uncommitted or unpushed work.
  </Card>
  <Card title="Stacked branches" icon="seti:git">
    Every worktree records its parent. `wtm tree` draws the forest, `wtm sync` rebases a branch and its descendants in order.
  </Card>
  <Card title="Many at once" icon="list-format">
    `wtm create a b c`, `wtm exec --all -- pnpm test`: one command across worktrees, in parallel, each with its own environment.
  </Card>
</CardGrid>

## Your whole stack, once per worktree

Configure it once, share it with `wtm run export`, and every developer and every agent gets the full stack in its own worktree: its own ports, its own `COMPOSE_PROJECT_NAME`, its own database in a shared postgres, its own URL. Two branches run side by side; an agent can start the app it is working on and test it end to end without touching yours.

## Built for agents

wtm is meant to be driven by something other than a person. `wtm agents install` adds a skill that teaches Claude Code or Cursor the commands and their unattended forms. Data commands take `--output json`, every change takes `--yes`, exit codes are stable, and `wtm events` streams every change as JSON Lines.

```bash
wtm create feat/a feat/b --yes --output json
wtm run up feat/a --yes -d
wtm events --output json | jq -c 'select(.type == "worktree.provisioned")'
```

This site is also served as plain text for agents: [`llms.txt`](__BASE__/llms.txt), [`llms-full.txt`](__BASE__/llms-full.txt).

## Install

<Tabs syncKey="install">
  <TabItem label="Homebrew">
    ```bash
    brew install LucasPcq/tap/wtm
    ```
  </TabItem>
  <TabItem label="Go">
    ```bash
    go install github.com/LucasPcq/wtm@latest
    ```
  </TabItem>
  <TabItem label="Binary">
    Download the archive for your platform from the [releases](https://github.com/LucasPcq__BASE__/releases), then:

    ```bash
    tar -xzf wtm_*_linux_amd64.tar.gz   # or _linux_arm64, _darwin_amd64, _darwin_arm64
    sudo mv wtm /usr/local/bin/
    ```
  </TabItem>
</Tabs>

Then let `wtm go` change your directory, and set up a repository:

```bash
echo 'eval "$(wtm shell-init)"' >> ~/.zshrc   # ~/.bashrc for bash
cd your-repo && wtm init
```

macOS and Linux, amd64 and arm64; Windows through WSL2. A specific version, updating and the other details are in [Installation](__BASE__/guide/installation/).
